# Cooee Tools 3D

Aplicativo desktop em português com atalhos para Club Cooee, pesquisas de páginas oficiais, relógio, lembretes de eventos, galeria/capturas e atalhos seguros do Windows 10 e 11.

## Gerar instalador no Windows
1. Instale Node.js 20 ou superior.
2. Baixe este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute `npm install`.
5. Execute `npm run dist:win`.
6. O instalador será criado na pasta `dist`.

O GitHub Actions também gera o instalador automaticamente quando os arquivos principais são atualizados. Acesse **Actions** e baixe o artefato **Cooee-Tools-3D-Windows** quando a execução terminar.

## Segurança
Projeto independente e não oficial. Não injeta código, não altera arquivos/memória do jogo, não automatiza ações dentro do jogo e não contém cheats. Os ajustes do Windows são atalhos para configurações do próprio sistema; nenhuma otimização agressiva é aplicada automaticamente.
